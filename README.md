# 录课工作台 v0.6.1

此版本修复下载程序自动读取本机开发版视频库的问题。正式版资料目录为 `%APPDATA%/RecordedContentPlatform/library`；不会导入旧的 `%APPDATA%/luke-studio/library`。旧资料和原片保留，需要时可以手动导入。

发行 ZIP 不包含任何录制视频、字幕或用户数据库。新电脑首次打开为空视频库；同一正式版后续录制会保存在自己的正式版资料目录，升级不会自动清空。

Windows x64 下载见 [Releases](https://github.com/fu5chen/Recorded-Content-Platform/releases)。完整解压并双击“录课工作台.exe”。

# 录课工作台（Windows 公司内部版）

本项目提供 Windows 本地录制、视频播放管理和公司局域网观看。当前版本为 0.6.0 可试用版本，并非所有设想功能均已完成。

## 启动

打开 `release-clean/win-unpacked/录课工作台.exe`。整个 `win-unpacked` 文件夹需要一起保留，不能单独移动其中的 exe。

## 日常使用

1. 在“课程管理”创建课程。
2. 打开“录制工作室”，填写标题、选择课程、屏幕或窗口与录制模式。
3. 如只录局部，点击“框选录制区域”，在预览中拖框，或输入 X/Y/宽/高，点击“使用此区域”。选择输出尺寸：常用 720p/1080p、所选区域原始大小，或自定义偶数宽高。位置以所选来源左上角为原点，更换来源会恢复全画面；输出比例不同时保留黑边。仅摄像头模式不提供屏幕区域裁切。
4. 选择是否录入麦克风和系统声音，点击开始。屏幕加人像模式会把摄像头画面放在右下角。
4. 切换到讲课窗口，可以暂停或继续，完成后点击“结束并保存”。等待保存完成。
5. 在媒体库播放、调整倍速、修改名称和课程，或导入 UTF-8 SRT / VTT 字幕。
6. 剪辑时填写开始和结束秒数，导出新的 MP4。原视频保留；字幕为独立字幕，不烧录到导出文件。
7. 已有视频也可以通过“导入视频”添加，文件会复制到本软件资料目录。

录制文件保存为 WebM，结束时自动修复索引便于拖动进度。需要通用 MP4 时用导出功能。MP4/WebM 的实际可播放性取决于文件里的编码；如特殊 MKV/AVI/MOV 无法播放，可先尝试导出转为 MP4。

## 同事通过局域网观看

1. 主机和同事设备连接同一个公司网络。
2. 在“公司局域网共享”点击开启，默认端口 8765。
3. 复制专用链接，在同事电脑或手机浏览器打开。
4. 共享期间保持软件运行、主机联网且不睡眠。
5. 点击停止后停止提供视频。重新开启会更换链接，使旧链接失效。

共享链接包含随机访问凭据，持有链接即可观看当前媒体库全部视频，且可能保存视频文件。本版不提供个人登录、按课程授权或防下载。已下载内容无法通过停止共享撤回。使用公司内部可信网络，不要做公网端口映射。网络管理员若禁止同网设备互访，需要其调整网络策略；Windows 防火墙需允许应用在专用网络访问。软件不会自动修改防火墙。

局域网页面支持倍速、视频拖动、字幕和当前浏览器的观看进度，不收集同事的中心化学习数据。传输采用 HTTP，不提供 TLS。多个同事观看会占用主机磁盘和局域网带宽，尚未进行大并发压测。

## 其他功能

- 本地学员档案保存姓名、课程和备注，不创建登录账号。
- “视频推流”可以把已录视频按正常速度推到已有 RTMP/RTMPS 服务，需自行提供完整地址（含密钥）。软件不创建直播服务器或直播观看页面。
- 所有资料保存在设置页显示的资料目录，通常为 `%APPDATA%/luke-studio/library`。完整备份该目录，包括 `library.json` 和 `media`。
- 移除媒体库条目会保留磁盘文件，避免误删；重新添加时可从资料目录导入。
- 意外退出时已写入的视频分段保留在 `media` 目录，但可能需要使用 FFmpeg 修复索引；未提供自动恢复向导。

## 尚未实现与验证边界

- 自动语音转字幕：目前支持导入现成字幕。
- 完整多轨时间线剪辑、拼接、转场和字幕烧录：目前支持按起止时间导出片段。
- 实时屏幕直播、聊天室和自动直播回放：目前支持录好视频向已有服务推流。
- 个人登录、按课程访问权限和集中学习统计：目前按专用链接共享整个库。
- 不需要收费，不开发支付与订单模块。
- 摄像头、真实麦克风、系统声音和外部直播连接需要在目标设备上人工验收；不能用自动测试代替。
- 未做安装包签名、自动更新、长时间连续录制和大并发压力验证。

## 开发与验证

环境：Node.js、Windows x64。执行 `npm ci`，确保 Electron 安装脚本正常下载运行时。将合法获取的 Windows FFmpeg 放入 `tools/ffmpeg.exe`。

- `npm start`：开发启动。
- `npm test`：局域网服务的链接权限、HTML 转义、Range、HEAD、字幕和停止共享测试。
- `npm run pack`：生成可运行的 Windows 文件夹。
- `npm run dist`：生成便携 exe，需能够下载 electron-builder 相关构建工具。
- `node_modules/electron/dist/electron.exe . --smoke`：以临时资料目录执行合成画面录制、分段写入、保存、播放读取、课程和学员资料、MP4 导出验证，结果写入 `smoke-result.json`。

Electron 的录屏接入依据 [desktopCapturer 文档](https://www.electronjs.org/docs/latest/api/desktop-capturer)，进程隔离依据 [官方安全说明](https://www.electronjs.org/docs/latest/tutorial/security)。当前项目锁定本机可获得的 Electron 40.10.2；正式分发前应升级到受支持版本并重新验证录制功能。

## 第三方组件

应用包含 Electron / Chromium（各自许可证见发行目录）及本机已有的 Gyan FFmpeg 完整构建（FFmpeg 9.0.1，包含 GPL 组件）。FFmpeg 来源：https://www.gyan.dev/ffmpeg/builds/ ，项目与源代码：https://ffmpeg.org/ ，许可证：https://ffmpeg.org/legal.html 。如对外分发需核对构建对应的许可证及源代码提供义务，不能只附此说明即视为完成合规。

区域和输出大小在开始录制前设置，录制期间固定。窗口录制区域会按窗口当前画面比例换算；录制时建议保持源窗口大小不变。为兼容 MP4，原始大小模式会将奇数宽高向下取为偶数。

## v0.6.0 桌面框选
点击“在桌面框选录制区域”，软件会自动最小化，并在所选屏幕显示透明选区层。拖动鼠标选择，点击确认或按 Enter；Esc / 右键取消。确认和取消都会恢复主窗口。选择窗口来源时，框选会切换为鼠标所在屏幕；多屏时可以先在来源下拉框选择对应屏幕。选择结果按屏幕缩放倍率转换为像素，默认按区域原始大小输出。录制前设置，录制中不可改动。

## v0.6.0 跳播与预览小窗
播放器下方的进度条支持点击、拖动并从选定时间继续播放。本地视频读取实现字节 Range；旧 WebM 首次打开时重新生成带索引的副本，原文件保留。首次准备长视频可能稍等。
录制开始后自动打开置顶预览小窗，显示裁切与人像混合后的实际输出画面，不播放录制音频。可移动、调整大小、关闭；关闭不影响录制，主窗口可重新打开，录制结束自动关闭。小窗启用 Windows 捕获排除；旧系统仍可能显示黑块，建议放在录制区域外。

## v0.6.0 窗口吸附选择
在桌面框选时，悬停资源管理器、浏览器等可见窗口，预览整窗边界；单击锁定，再确认。拖动自由选区时距窗口或屏幕边缘 10 个逻辑像素内会轻微吸附，按住 Alt 临时关闭吸附。根据窗口叠放顺序识别，不识别窗口内部文件行或按钮。选区是固定屏幕位置，后续移动目标窗口不会自动跟随。窗口列表在打开选区时读取一次，窗口位置发生变化需取消后重选。

## v0.6.0 低延迟预览
录制预览由每秒 5 帧 JPEG 编解码改为最大边长 480 像素的原始画面传输，目标约 30 帧每秒。仅允许一帧在途，小窗绘制后确认，再发送下一帧，避免积压。关闭或最小化小窗停止预览传输，录制继续；恢复或重新打开继续显示。实际流畅度受录制分辨率、设备负载和系统调度影响，正式视频的画质设置不变。

发布前运行 `npm run audit:release` 检查发行目录及 app.asar 不含视频和数据库。构建只复制明确列出的 FFmpeg 与窗口边界脚本。
