使用说明

  1. 让这台电脑和同事的设备连接同一公司网络。
  2. 开启共享，将生成的链接发送给同事。
  3. 保持软件运行，电脑不要进入睡眠。
  4. 需要停止访问时，点击“停止共享”。再次开启会生成新链接，旧链接失效。

所有持链接的人均可观看当前视频库，也可能保存视频文件。此版本按整个媒体库共享，不提供个人账号或按课程授权。

若无法访问，请检查 Windows 防火墙是否允许此程序在专用网络通信，以及公司网络是否禁止设备互访。无需公网或路由器端口映射。

直播上线需要什么？

  1. 直播平台或自建直播服务器
  2. 服务提供的完整推流地址

当前功能与使用范围

本机功能：录制屏幕 / 摄像头 / 混合人像，麦克风与系统声音，暂停续录，媒体导入，播放与倍速，观看进度，字幕导入，片段 MP4 导出，课程分类，学员档案，已有视频 RTMP 推流。

已提供公司局域网只读共享，不需要支付账号。共享期间需要保持本机在线；自动字幕、完整剪辑时间线及实时屏幕直播尚未实现。若未来需要个人账号权限、跨互联网访问或中心化学习报表，需要补充后端。
